# NorthStar Supply Chain Consulting Pitch Deck

This repository contains a polished 5-slide pitch deck for a supply chain consulting business.

## Open the deck

Simply open `index.html` in a browser.

## Features

- 5-slide executive pitch deck
- Modern consulting aesthetic
- Mobile-responsive layout
- Keyboard navigation with arrow keys
- Previous/next slide controls

## Customization

Update the branding and messaging in `index.html` to match your business name, service focus, and target clients.

## Suggested business positioning

This deck is built around a premium supply chain consulting firm that helps businesses:

- Reduce logistics and fulfillment costs
- Improve inventory efficiency
- Build more resilient operating networks
- Strengthen service levels and customer reliability

## Files

- `index.html` — deck structure and slide content
- `styles.css` — visual design and layout
- `script.js` — slide navigation
